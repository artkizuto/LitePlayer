# LitePlayer

A lightweight music player made because Chrome kept eating my RAM while I was drawing manga.

## Why?

I just wanted to play my local MP3 files without opening YouTube.

That's it.

## Features

- Open Folder
- Playlist
- Shuffle
- Repeat
- Very low RAM usage
